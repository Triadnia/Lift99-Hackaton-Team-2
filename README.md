# AI Literacy Teacher Assistant

Тренажер AI-грамотності для вчителів, створений за 4-годинний хакатон. Проект допомагає вчителям аналізувати плани уроків та створювати квізи, навмисно генеруючи помилки ("навчальні пастки") за допомогою ШІ для перевірки пильності викладачів.

## Формула AI-грамотності

Оцінка грамотності розраховується за такою формулою:

$$
L_{AI} = \left( \frac{E_{detected}}{E_{total}} \times 100\% \right) \times W_1 + (C_{prompt} \times 100\%) \times W_2
$$

Де:
- $E_{detected}$ — кількість знайдених вчителем помилок (галюцинацій).
- $E_{total}$ — загальна кількість закладених AI помилок у згенерованому матеріалі.
- $C_{prompt}$ — якість складеного промпту (від 0 до 1).
- $W_1, W_2$ — вагові коефіцієнти (наприклад, 0.7 та 0.3 відповідно).

## Як запустити

1. Встановіть залежності:
```bash
pip install -r requirements.txt
```

2. Створіть файл `.env` та додайте ваш ключ Groq API (або іншого сумісного з OpenAI провайдера):
```
GROQ_API_KEY=your-api-key-here
```

3. Запустіть застосунок:
```bash
streamlit run app.py
```
